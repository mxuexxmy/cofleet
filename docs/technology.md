# 技术选型与原型验证

记录日期：2026-11-02。

## 已确认方向

客户端主要在托盘常驻，偶尔打开设置。以低空闲资源占用、后台稳定运行和 Windows、macOS、Linux 支持为优先目标。

- 微服管理中心：首选 Rust。
- 电脑后台 Agent：首选 Rust，与管理中心共享协议定义及适用的通用逻辑。
- 电脑托盘：首选 Rust 与平台适配，独立于后台服务。
- 管理网页：计划使用 TypeScript，具体框架待定。
- 设置：日常管理优先使用 Web；首次连接、本机授权、断线诊断保留本地入口。
- 暂不引入完整 Tauri 或 Qt 外壳；如独立设置窗口成为必要需求，再进行对比验证。

这是用户认可的首选方向，尚未通过三平台原型验证，不代表技术栈已最终冻结。Go 保留为开发复杂度或集成成本不符合预期时的备选。

## 最小原型范围

1. 提供测试管理端与 Agent，验证注册、心跳、状态上报及断线重连。开发机上的模拟连接不能代替懒猫微服通道验证。
2. Agent 独立运行；托盘显示连接状态，提供暂停接收新任务、恢复、打开管理页和退出托盘操作。
3. 通过操作系统权限约束的本地 IPC 连接后台服务，验证其他本机用户无法任意控制 Agent。
4. 提供离线可用的最小本地配置入口；具体形态待验证，不要求首版具备完整设置窗口。
5. 分别验证 Windows 服务、macOS 后台服务和 Linux systemd；后台服务不依赖托盘或用户持续登录。
6. 验证实际懒猫客户端接口、账号归属、凭据保护及微服访问方式后，再确认通信实现。

原型不执行任意远程命令，不操作真实容器或部署业务应用。退出托盘、暂停派单、停止服务为不同操作；已有负载的停止策略另行定义。

## 资源与行为验收

暂不承诺固定内存数值。先建立实测基线，再根据目标设备制定预算。

| 场景 | 记录内容 |
| --- | --- |
| 仅 Agent，空闲至少 10 分钟 | 常驻内存、CPU、线程/句柄或文件描述符、心跳流量 |
| Agent 加托盘 | 两者及子进程的总内存、空闲 CPU |
| 打开及关闭设置 | 峰值内存、关闭后是否回落、本地入口是否离线可用 |
| 断网与恢复 | 重试频率、CPU、内存趋势、是否自动恢复及重复注册 |
| 退出托盘、注销与重启 | 后台是否按预期继续运行、是否按配置启动 |
| 微服管理端空闲及多节点连接 | 内存、CPU、连接数、状态处理延迟 |

测试必须记录系统版本、CPU 架构、构建模式、节点数与测量方法。使用 release 构建；各系统内存统计口径分别注明，不能直接将 RSS、私有工作集和共享内存混为同一指标。管理网页使用的浏览器资源单独记录。检查持续运行时资源是否增长，不能只测启动瞬间。

## 当前状态

已实现测试管理端、Agent、命令行配置及轻量托盘。当前 Linux 环境已安装 Rust 工具链，并通过编译、静态检查、单元测试和进程级闭环测试。托盘通过桌面 StatusNotifier/DBusMenu 接口验证注册、暂停、恢复及退出后 Agent 继续运行。

Unix 使用私有目录与 socket；Windows 已编写用户 ACL 与命名管道适配，但尚未实机验证。已配置三平台 CI，未将未运行的 CI 标记为通过。Linux 提供 systemd 样例、macOS 提供 launchd 模板，未安装；Windows 原生服务入口尚未实现。

本机模拟管理端的验证不代替真实懒猫设备通道、LC 02、Windows 或 macOS 验证。运行与限制见 [开发文档](development.md)。

已记录本机 release 原型的 [30 秒资源快照](performance.md)，尚不构成长时间资源验收。

控制面已按 [lzc-mesh 架构](lzc-mesh-reference.md) 改为 WebSocket 中枢，增加实验懒猫登录适配和按账号隔离；真实平台通道仍未验收。

默认微服测试版已安装，Linux 到微服的真实登录、WSS、状态请求和容器重启重连验证通过；结果与未验证项见 [部署记录](deployment/lazycat-validation.md)。
